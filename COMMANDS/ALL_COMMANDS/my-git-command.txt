# 🔄 CLONE A REPOSITORY
git clone https://github.com/username/repo.git
# → Copies the remote repository to your local machine

# 🔍 CHECK STATUS
git status
# → Shows the current branch, staged/unstaged files, and uncommitted changes

# 🌿 CREATE AND SWITCH TO A NEW BRANCH
git checkout -b branch-name
# → Creates and switches to a new branch (used for working on features or fixes)

# 🚥 SWITCH TO AN EXISTING BRANCH
git checkout branch-name
# → Switches to another branch

# 📂 STAGE FILES FOR COMMIT
git add .
# → Adds all changed files to the staging area

git add filename.ext
# → Adds a specific file to the staging area

# 💾 COMMIT STAGED CHANGES
git commit -m "your descriptive message"
# → Saves a snapshot of the staged changes with a message

# 🔼 PUSH BRANCH TO REMOTE
git push origin branch-name
# → Sends your branch and commits to the remote repo

# 📥 PULL LATEST CHANGES FROM REMOTE
git pull origin branch-name
# → Updates your local branch with changes from the remote branch

# 🔄 MERGE ANOTHER BRANCH INTO CURRENT
git merge other-branch-name
# → Combines changes from the specified branch into your current branch

# 🔁 VIEW COMMIT HISTORY
git log
# → Shows commit history (press `q` to quit)

git log --oneline
# → Short summary of commit history

# 🧹 DELETE A LOCAL BRANCH
git branch -d branch-name
# → Deletes a branch locally (after merging)

# 🗑️ DELETE A REMOTE BRANCH
git push origin --delete branch-name
# → Removes the branch from the remote GitHub repo

## Fix: Clean Up Old Remote Branches Locally(After being deleted)
git remote prune origin

# 🚀 SET UPSTREAM FOR FIRST PUSH
git push --set-upstream origin branch-name
# → Links your local branch with the remote version

# 🎭 STASH UNCOMMITTED CHANGES
git stash
# → Temporarily saves your changes without committing

# 🔄 APPLY STASHED CHANGES
git stash pop
# → Restores your stashed changes

# ❌ UNSTAGE A FILE
git reset HEAD filename.ext
# → Removes a file from staging area

# ❎ DISCARD FILE CHANGES
git checkout -- filename.ext
# → Restores the file to the last committed version

# 🧑‍💻 CONFIGURE GIT USER INFO (Run once)
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
# → Sets your identity for all commits

# 🧠 CHECK BRANCHES
git branch
# → Lists all local branches

git branch -r
# → Lists all remote branches

# 🌐 ADD A REMOTE REPO
git remote add origin https://github.com/username/repo.git
# → Connects your local project to a remote GitHub repo

# 🔍 SEE REMOTES
git remote -v
# → Lists the current remotes connected to your repo

git fetch

git pull origin main

git checkout your-feature-branch
git merge main            # merge latest main into your feature branch
git rebase main           # cleaner commit history, optional if you understand rebase

🔹 1. Remove the last commit (but keep your files)

If you committed but haven’t pushed (or want to undo locally):

git reset --soft HEAD~1

👉 This removes the last commit but keeps your changes staged.

If you want to keep changes but unstage them:

git reset --mixed HEAD~1
🔹 2. Remove the last commit completely (delete changes too)
git reset --hard HEAD~1

⚠️ This deletes the commit AND your changes permanently.

🔹 3. Undo a commit that is already pushed to GitHub

If you already pushed and want to remove it:

git reset --hard HEAD~1
git push origin main --force

👉 Replace main with your branch name.

⚠️ Be careful: --force rewrites history (can affect teammates).

🔹 4. Remove GitHub connection (keep project locally)

If you want to disconnect your project from GitHub completely:

rm -rf .git
